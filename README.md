# GRT FindIt Portal

 Smart College Lost and Found Management System

📌 Project Overview

GRT FindIt is a web-based Lost and Found Portal designed to help students and faculty members report, search, and recover lost belongings within the college campus.

The portal provides a centralized platform to make the lost-and-found process easier, faster, and more organized.

 🎯 Objectives

- Provide a centralized platform for lost and found items.
- Help students report lost belongings.
- Make it easier to find and claim missing items.
- Improve communication between students and the college community.
- Reduce the time required to recover lost belongings.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
